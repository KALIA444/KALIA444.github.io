## Mettre le portfolio en ligne avec GitHub Pages (10 minutes)

1. Connecte-toi sur github.com avec ton compte **KALIA444**.
2. Clique sur **New repository** (le bouton vert « New »).
3. Nomme le dépôt exactement **`KALIA444.github.io`**, coche **Public**, puis clique sur **Create repository**.
4. Sur la page du dépôt, clique sur **uploading an existing file**.
5. Glisse **tout le contenu** du dossier `portfolio` : le fichier `index.html`, le fichier `README.md` et le dossier `docs` avec les 4 PDF.
6. Clique sur **Commit changes**.
7. Va dans **Settings → Pages**. Dans « Branch », choisis **main** et **/ (root)**, puis clique sur **Save**.
8. Attends 1 à 2 minutes. Ton portfolio est en ligne sur : **https://KALIA444.github.io**

Mets ensuite ce lien sur ton CV, dans ton profil LinkedIn et dans tes mails de candidature.

## Mettre à jour un document

Pour changer un CV ou une lettre, remplace le PDF dans le dossier `docs` par la nouvelle version **en gardant exactement le même nom de fichier**.
